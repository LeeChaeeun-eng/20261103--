ILLU MARKET 2026 웹사이트

실행 방법
1. 압축을 해제합니다.
2. illu_market_website 폴더 안의 index.html을 브라우저에서 엽니다.
3. 사전등록 버튼은 register.html로 이동합니다.
4. 전체 일정 보기 / 전체 프로그램 보기 버튼은 팝업 모달을 엽니다.

구성
- index.html : 메인 행사 안내 페이지
- register.html : 사전등록 데모 페이지
- css/style.css : 메인 스타일
- css/register.css : 신청 페이지 스타일
- js/main.js : 메뉴 및 팝업 동작
- js/register.js : 신청 폼 동작
- assets/ : 페이지에 삽입된 로컬 SVG 이미지 파일

참고
가상 행사 정보와 신청 페이지입니다. 신청 정보는 서버로 전송되거나 저장되지 않습니다.
실제 접수 기능을 사용하려면 백엔드 또는 폼 서비스 연결이 필요합니다.
